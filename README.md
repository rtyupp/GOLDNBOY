# GOLDNBOY — بوت إشارات الذهب XAUUSD

بوت تيليجرام يعتمد على **الأسعار اللحظية والاستراتيجيات والمؤشرات الفنية** لتحليل الذهب وتحديد فرص التداول المحتملة.
**القرار كله من قواعد برمجية قابلة للاختبار، وبلا مصدر أخبار.** مفتاح DeepSeek اختياري ويستخدم للشرح فقط (انظر «المساعد»).

> قد لا تصدر إشارة إن لم تتحقق الشروط. لا توجد استراتيجية تضمن الربح، والإشارات للمعلومات فقط وليست نصيحة مالية.

## كيف يعمل
```
Swissquote (سعر لحظي مجاني) ─► شموع 1m→4H ─► مؤشرات + هيكل + سيولة + مناطق
   ─► 7 استراتيجيات ─► Confluence ─► احتمال تاريخي ─► مخاطرة ─► BUY / SELL / NO TRADE ─► Telegram + شارت ─► TP1/TP2
```
التاريخ من Dukascopy (مجاني). إن فشل أي مصدر يتوقف البوت عن الإشارات بدل أن يخمّن.

## الاستراتيجيات (7)
الخمس الأصلية: ارتداد مع الاتجاه · اصطياد السيولة · الاختراق · الانعكاس · VWAP.
SMC (جديدتان، مبنيتان على أدوات المشروع دون تكرار وظائفه، في `goldbot/strategies/smc.py`):
- **SMC OTE + FVG**: ساق حركة ← كسر هيكل BOS/CHoCH ← ارتداد إلى OTE (62–79%) يتقاطع مع فجوة FVG ← شمعة تأكيد. (Order Block وسحب سيولة وزخم تزيد التقييم.)
- **SMC Sweep-MSS-FVG**: سحب سيولة ← تغيّر هيكل MSS ينتج FVG ← دخول عند عودة السعر للفجوة.

كل إعداد يمر بـ: Confluence ≥ 60، وفحص الاحتمال التاريخي (يحجب الإعداد فقط إذا وُجدت عينة كافية وكانت ضعيفة)، وحدود السبريد، والجلسة، وتعارض الفريمات، ثم إدارة المخاطرة (وقف، هدف 1، هدف 2، نقل الوقف للتعادل بعد الهدف 1، إشعار عند كل هدف).

## التشغيل على Render
1. ارفع المشروع إلى GitHub (الملف `.env` مستبعد في `.gitignore`).
2. Render ← New ← Blueprint (يقرأ `render.yaml`) أو Web Service بـ Docker.
3. متغيرات البيئة: `TELEGRAM_BOT_TOKEN` و`TELEGRAM_ADMIN_IDS` (اكتب `/id` للبوت ليعطيك رقمك) و`BOT_MODE=live` عند الجاهزية.
4. ابدأ بـ `BOT_MODE=paper` (يسجّل بلا إرسال) وراقب `/status`.
المفاتيح تُوضع في لوحة Render فقط، ولا تُكتب في الكود.

## محليًا
```bash
pip install -r requirements.txt
cp .env.example .env        # ثم املأ التوكن
python -m goldbot check     # فحص الاتصالات
python -m goldbot run
python -m unittest discover -s tests -t .
```

## المساعد (DeepSeek) — اختياري ويعمل تلقائيًا
ضع `DEEPSEEK_API_KEY` في متغيرات Render فيعمل دون أي زر أو إعداد. بدون المفتاح يبقى صامتًا تمامًا.
- **شرح كل إشارة:** تصل الإشارة أولًا كما هي، ثم رسالة «📝 شرح الإشارة» تشرح سبب اجتماع الشروط.
- **ملخص يومي (20:00 UTC) وأسبوعي (الجمعة):** الأرقام من سجل الصفقات، وتعليق DeepSeek يُضاف إن توفر.
- **أسئلة حرة:** اكتب أي سؤال عادي في المحادثة الخاصة فيجيب من بيانات البوت فقط (السعر، آخر إعداد، الإحصائيات، الجلسة).

**لا يقرر ولا يعدّل:** الدخول والوقف والأهداف تُحسب بالقواعد قبل أن يراها النموذج، وفشل DeepSeek (رصيد، مهلة، مفتاح خاطئ) لا يؤثر على الإشارات. سقف يومي للاستدعاءات (`assist.max_calls_per_day`) لضبط التكلفة. النموذج الافتراضي `deepseek-v4-flash` (يمكن تغييره بـ `DEEPSEEK_MODEL`). الشروح آلية وقد تخطئ في الصياغة؛ ليست نصيحة مالية.

## الاختبار التاريخي الواقعي والمقارنة
```bash
python -m goldbot backtest --days 60 --tf 5m --store     # يبني سجل الاحتمال التاريخي
python -m goldbot compare  --days 60 --tf 5m             # الحالية مقابل الحالية+SMC مع التكاليف
```
التكاليف في `config/config.yaml` ← `backtest`: السبريد `0.30$` + انزلاق الدخول `0.10$` + انزلاق إضافي عند ضرب الوقف `0.15$` (أهداف Limit بلا انزلاق). الأمر `compare` يطبع أيضًا نفس التشغيل بلا تكاليف لإظهار أثرها، ويحكم على كل استراتيجية SMC بقاعدة: ≥30 صفقة، متوسط R>0، PF>1، وR>0 خارج العينة.
**شغّل `compare` على بيانات Dukascopy الحقيقية قبل الاعتماد على نتائج SMC؛ البيانات الصناعية تختبر البرمجة فقط ولا تثبت ربحية.**
