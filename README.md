# GOLDNBOY — بوت إشارات الذهب XAUUSD

بوت تيليجرام يعتمد على **الأسعار اللحظية والاستراتيجيات والمؤشرات الفنية** لتحليل الذهب وتحديد فرص التداول المحتملة.
**القرار كله من قواعد برمجية قابلة للاختبار، وبلا مصدر أخبار.** مفتاح DeepSeek اختياري ويستخدم للشرح فقط (انظر «المساعد»).

> قد لا تصدر إشارة إن لم تتحقق الشروط. لا توجد استراتيجية تضمن الربح، والإشارات للمعلومات فقط وليست نصيحة مالية.

## كيف يعمل
```
Swissquote (سعر لحظي مجاني) ─► شموع 1m→4H ─► مؤشرات + هيكل + سيولة + مناطق
   ─► 7 استراتيجيات ─► Confluence ─► احتمال تاريخي ─► مخاطرة ─► BUY / SELL / NO TRADE ─► Telegram + شارت ─► TP1/TP2
```
التاريخ من Yahoo Finance (مجاني، GC=F ذهب آجل، ~4 أسابيع من 1m). Dukascopy يبقى متاحًا عبر `providers.history: dukascopy`. إن فشل أي مصدر يتوقف البوت عن الإشارات بدل أن يخمّن.

«⚙️ المزيد»: 🟢 حالة النظام · 🕒 الجلسة الحالية · 📌 آخر إشارة · 🛑 لماذا لا توجد توصية؟ · 🧪 إعادة بناء السجل · ❓ المساعدة · 🔙 القائمة الرئيسية.
اللوحة تبقى ظاهرة أثناء التنقل. تظهر في المحادثات الخاصة فقط (تيليجرام لا يدعمها في القنوات). الأوامر `/price /analysis /signal /market /stats /history /last /why /session /status /train /help /id` تعمل أيضًا.
`/why` = لوحة تشخيص تعرض البوابة/السبب الذي أوقف آخر إشارة (البوابات العامة، أقرب إعداد ونتيجته، درجة الالتقاء مقابل العتبة، والموانع).

## وضع السكالب على 15 دقيقة
ملف `config/scalp.yaml` يضبط أدوات أسرع: عتبات التقاء/نتيجة أوسع، وقف أقرب، وأهداف أسرع، وخروج زمني بعد 45 دقيقة.
- تشغيل: `python -m goldbot run --profile scalp` أو `GOLDBOT_PROFILE=scalp` (على Render: أضف متغير البيئة).
- الفرق الجوهري عن الافتراضي: وضع السكالب **لا يشترط موافقة الفريمات الكبيرة** (`strategies.require_htf_alignment: false`) ولا يمنع الإشارة لمجرد تعارض 4H/1H (`confluence.ignore_htf_conflict: true`)، لأن صفقات 15m قصيرة الهدف. على بيانات 28 يومًا: 32 صفقة مقابل 6 في الوضع الافتراضي (PF 1.16).
- المقارنة (نفس البيانات، فريم 15m): الافتراضي ≈12 صفقة مقابل السكالب ≈33 صفقة.

## الاستراتيجيات (9)
الخمس الأصلية: ارتداد مع الاتجاه · اصطياد السيولة · الاختراق · الانعكاس · VWAP.
SMC (جديدتان، مبنيتان على أدوات المشروع دون تكرار وظائفه، في `goldbot/strategies/smc.py`):
- **SMC OTE + FVG**: ساق حركة ← كسر هيكل BOS/CHoCH ← ارتداد إلى OTE (62–79%) يتقاطع مع فجوة FVG ← شمعة تأكيد. (Order Block وسحب سيولة وزخم تزيد التقييم.)
- **SMC Sweep-MSS-FVG**: سحب سيولة ← تغيّر هيكل MSS ينتج FVG ← دخول عند عودة السعر للفجوة.
المضافتان (من مقارنة مع استراتيجيات سكالب الذهب المعروفة، في `goldbot/strategies/impl.py`):
- **نطاق الافتتاح ORB**: إغلاق خارج نطاق افتتاح جلسة لندن/نيويورك (±سيولة وجود نطاق نشط). من أقوى أنماط السكالب على الذهب.
- **الأرقام المستديرة**: رفض عند مستوى كامل ($10 افتراضيًا) مع شمعة تأكيد.

كل إعداد يمر بـ: Confluence ≥ 68.4 (يعادل 70 في النسخة الأصلية)، وفحص الاحتمال التاريخي (يحجب الإعداد فقط إذا وُجدت عينة كافية وكانت ضعيفة)، وحدود السبريد، والجلسة، وتعارض الفريمات، ثم إدارة المخاطرة (وقف، هدف 1، هدف 2، نقل الوقف للتعادل بعد الهدف 1، إشعار عند كل هدف).

## التشغيل على Render
1. ارفع المشروع إلى GitHub (الملف `.env` مستبعد في `.gitignore`).
2. Render ← New ← Blueprint (يقرأ `render.yaml`) أو Web Service بـ Docker.
3. متغيرات البيئة: `TELEGRAM_BOT_TOKEN` و`TELEGRAM_ADMIN_IDS` (اكتب `/id` للبوت ليعطيك رقمك) و`BOT_MODE=live` عند الجاهزية.
4. ابدأ بـ `BOT_MODE=paper` (يسجّل بلا إرسال) وراقب `/status`.
المفاتيح تُوضع في لوحة Render فقط، ولا تُكتب في الكود.

## مصادر البيانات والأعطال
- **اللحظي:** Swissquote Public Quotes (عام، بلا مفتاح).
- **التاريخي:** Yahoo Finance (`GC=F`)، يوفّر 1m حتى ~4 أسابيع. Dukascopy متاح بديلًا/احتياطيًا.
- إن ظهر «Yahoo غير متاح» فالمصدر غير قابل للوصول من الشبكة الحالية؛ البوت يعيد المحاولة ولا يحلل على بيانات ناقصة.
- **Dukascopy (اختياري):** يشتهر بحجب/تقييد الطلبات من خوادم السحابة (HTTP 429/503). إن اخترته، الكود يحمّل بـ3 خيوط مع فاصل، يحترم `Retry-After`، يتوقف بعد 8 رفضات متتالية، ويحفظ كل ساعة نجحت في `data/cache/duka`. على Render المجاني القرص مؤقت.
- إن ظهر «Dukascopy غير متاح (HTTP 429)» جرّب تركه والاعتماد على Yahoo الافتراضي، أو ضع `providers.history: yahoo_dukascopy` لاستخدام Yahoo أساسًا وDukascopy احتياطًا.

## الحماية والاستمرارية (إضافات)
- **فلتر الأخبار الاقتصادية:** مصدر مجاني بلا مفاتيح (تقويم ForexFactory). يوقف الإشارات قبل/بعد الأخبار الحمراء (CPI/NFP/FOMC) بـ15 دقيقة. الفشل «آمن»: إن تعذّر التقويم لا يُحجب شيء. اعرضه بأمر `/news`.
- **تنبيه «فرصة قاربت»:** إن بلغ أفضل إعداد درجة عالية (افتراضيًا ≥80) لكن مُنع ببوابة، تصل رسالة توضح الإعداد والدرجة وسبب المنع (بتهدئة ساعة لكل إعداد). تنبيه فقط، ليس توصية.
- **حفظ السجل عبر إعادة التشغيل:** على Render المجاني (بلا قرص) يُنسخ `journal.sqlite` تلقائيًا إلى **Gist خاص** ويُستعاد عند الإقلاع، فلا يضيع التعلّم مع كل نشر. يحتاج `GITHUB_TOKEN` (صلاحية gist). يعمل بأمان: أي خطأ لا يوقف البوت ولا يمسّ السجل المحلي.

## المساعد (DeepSeek) — اختياري ويعمل تلقائيًا
ضع `DEEPSEEK_API_KEY` في متغيرات Render فيعمل دون أي زر أو إعداد. بدون المفتاح يبقى صامتًا تمامًا.
- **شرح كل إشارة:** تصل الإشارة أولًا كما هي، ثم رسالة «📝 شرح الإشارة» تشرح سبب اجتماع الشروط.
- **ملخص يومي (20:00 UTC) وأسبوعي (الجمعة):** الأرقام من سجل الصفقات، وتعليق DeepSeek يُضاف إن توفر.
- **أسئلة حرة:** اكتب أي سؤال عادي في المحادثة الخاصة فيجيب من بيانات البوت فقط (السعر، آخر إعداد، الإحصائيات، الجلسة).

**لا يقرر ولا يعدّل:** الدخول والوقف والأهداف تُحسب بالقواعد قبل أن يراها النموذج، وفشل DeepSeek (رصيد، مهلة، مفتاح خاطئ) لا يؤثر على الإشارات. سقف يومي للاستدعاءات (`assist.max_calls_per_day`) لضبط التكلفة. النموذج الافتراضي `deepseek-v4-flash` (يمكن تغييره بـ `DEEPSEEK_MODEL`). الشروح آلية وقد تخطئ في الصياغة؛ ليست نصيحة مالية.

## الاختبار التاريخي الواقعي والمقارنة
```bash
python -m goldbot backtest --days 60 --tf 5m --store     # يبني سجل الاحتمال التاريخي
python -m goldbot compare  --days 60 --tf 5m             # الحالية مقابل الحالية+SMC مع التكاليف
```
التكاليف في `config/config.yaml` ← `backtest`: السبريد `0.30$` + انزلاق الدخول `0.10$` + انزلاق إضافي عند ضرب الوقف `0.15$` (أهداف Limit بلا انزلاق). الأمر `compare` يطبع أيضًا نفس التشغيل بلا تكاليف لإظهار أثرها، ويحكم على كل استراتيجية SMC بقاعدة: ≥30 صفقة، متوسط R>0، PF>1، وR>0 خارج العينة.
**شغّل `compare` على بيانات Dukascopy الحقيقية قبل الاعتماد على نتائج SMC؛ البيانات الصناعية تختبر البرمجة فقط ولا تثبت ربحية.**
